# Bluent consumer skill bundle

This directory contains the portable, retrieval-oriented Bluent consumer skill introduced for Issue #406.

The bundle intentionally does not duplicate the complete component API. `SKILL.md` routes agents to compact decision/foundation/pattern references, which in turn point to canonical documentation and verified task examples. `COMPONENT-INDEX.md` marks families whose canonical references are still pending so agents inspect current source/demo rather than guess.

Canonical documentation remains under `docs/`; the maintained coverage ledger is `docs/components/inventory.md`.
