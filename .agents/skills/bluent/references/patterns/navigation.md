# Navigation pattern

Canonical example: `docs/examples/tasks/navigation-and-layout.md`.

For Bluent application navigation, route needs through `NavList`, `Menu`/`MenuList`, `TabList`, `Breadcrumb`, and `Toolbar` as appropriate. Use standard Blazor `Router`, `NavLink`, and `NavigationManager` where the canonical task example does so; Bluent does not replace framework routing.

Exact family API pages are still pending. Use current demo/source for parameters, composition and keyboard behavior rather than guessing.
